# 平板借還站（雲端版）

取代平板車上的紙本借用簿：在車上放一台「借還平板」，借用人掃描（或點選）平板編號、登入學校 Google 帳號就完成借出；歸還時掃一下就好。

**所有資料都在雲端**（it@lsps.tp.edu.tw 的 Google 試算表）：借用紀錄、平板清單、感應卡名單、管理密碼都不存在平板上。換平板、清除瀏覽器資料、換瀏覽器，打開網址就能直接用，不用重新設定。

- 借還站：https://pingking0220.github.io/tablet-loan/ （多台平板車時用 `?cart=車名` 指定，例如 `…/tablet-loan/?cart=教務處`）
- 使用說明（給老師、學生）：https://pingking0220.github.io/tablet-loan/guide.html
- 標籤產生器：https://pingking0220.github.io/tablet-loan/labels.html

| 檔案 | 用途 |
|---|---|
| `index.html` + `app.js` | 借還站（放在平板車上的 iPad 開這頁） |
| `labels.html` | 條碼標籤／借用證產生器（平板清單直接讀雲端） |
| `guide.html` | 給老師、學生看的借還說明 |
| `common.js` | 共用設定、平板清單、QR 產生、雲端後端網址 |
| `gas/Code.gs` | Google 試算表後端（已部署在 it@ 帳號，第 3 版） |
| `vendor/` | 掃描（zxing-wasm 3.1.4）、QR（qrcode-generator 1.4.4）、一維條碼（JsBarcode 3.11.6） |
| `sw.js` / `manifest.webmanifest` | 離線快取（網路斷了借還站照樣能開，借還動作先暫存） |

## 借還方式（四種可以混用）

1. **鏡頭掃條碼**：平板背面貼 QR Code，對著借還平板的鏡頭（預設前鏡頭）掃。
2. **直接點選**：按「👆 不用掃描，直接點選平板編號」，綠色＝在車上可借、橘色＝借出中可還，可以一次選很多台。
3. **感應卡**：外接讀卡機後，刷登錄過的學生證／教職員證／悠遊卡＝帶入借用人（由雲端辨識）；平板背面貼 NFC 貼紙也能刷平板。
4. **條碼槍／手動輸入**：USB／藍牙條碼槍直接掃；或在輸入框打編號（只打數字 7 會自動補成完整編號）。

借出時要選身分並**登入學校 Google 帳號**：學生 `@stu.lsps.tp.edu.tw`、老師／職員 `@lsps.tp.edu.tw`。網域不符會被擋下。借完會自動開一個登出分頁、2.5 秒後關掉，避免下一個人選到上一個人的帳號。

歸還不用登入：掃一下（或點選）就好，8 秒內可以按「復原」。前一天以前借出還沒還的會標成「逾期」。

掃到「不在平板清單」的條碼時，右側會留著提示（掃到什麼、清單是哪些編號），管理者可以直接按「把它加入平板清單」。

## 借還平板（iPad）設定

1. 用 **Safari** 開借還站網址（不要「加入主畫面」：主畫面模式的 Google 登入彈窗在 iOS 上不穩定）。建議加入 Safari 書籤，或用 Jamf 推送網頁捷徑。
2. 「設定 → Safari → 相機」改「允許」，不然每次重開都要按允許。
3. 「設定 → Safari → 阻擋彈出式視窗」如果 Google 登入視窗打不開就關掉。
4. 「設定 → 螢幕顯示與亮度 → 自動鎖定」改「永不」，接著充電線。
5. 開「引導使用模式」（設定 → 輔助使用 → 引導使用模式，三下側邊按鈕啟動），學生就跳不出 Safari。用 Jamf 管理的話也可以用單一 App 模式鎖 Safari。

打開網址後：雲端只有一台平板車就直接進入；有多台會讓你選一次（網址會自動加上 `?cart=車名`）。新 iPad 也可以在已經在用的借還平板「管理 → 雲端」用相機掃那裡的 QR Code。

平板若是立在車上面向使用者，用前鏡頭（預設）；平放就到「管理 → 基本設定」換後鏡頭，或按鏡頭畫面右下角 🔄。鏡頭是每台平板自己的設定，其他設定都在雲端、所有借還平板共用。

## 管理

- 右上角 ⚙️ → 輸入**管理密碼**（存在雲端，所有借還平板共用；預設 1234，第一次請在「基本設定」改掉）。密碼連錯 8 次會鎖 10 分鐘。
- 「借用紀錄」：從雲端讀取完整紀錄（姓名、帳號），可歸還、作廢、匯出 Excel 可開的 CSV。
- 「平板清單」「基本設定」「感應卡」：存檔就直接寫到雲端，其他借還平板 30 秒內（有人在用時）自動更新。
- 「雲端」：連線狀態、這台平板車的網址與 QR Code。
- 建立第二台平板車：開借還站網址，在選平板車的畫面按「建立一台新的平板車」。

## 隱私與安全（雲端版）

後端網址寫在公開的程式裡，所以後端做了這些保護：

- 一般畫面（借還站的現況、最近紀錄）只拿得到**遮蔽過的姓名**（王○明），不含 Google 帳號、用途。
- 完整紀錄、感應卡名單、修改設定、作廢紀錄都要先輸入管理密碼（由雲端驗證，換一張 12 小時有效的通行證）。
- 一般的借還請求只能「新增借出」或「標記歸還」，改不了別人的姓名，也不能作廢。
- 感應卡名單不會傳到平板；刷卡時由雲端查出是誰，並把姓名寫進紀錄。

## 列印條碼標籤

管理 → 列印條碼 → 開啟標籤產生器（或直接開 `labels.html`）。平板清單直接讀雲端，和借還站一致；有多台平板車可以下拉切換。

- 建議用 **QR Code**：任何角度都掃得到。系統會自動挑「不讓 QR 變大的最高容錯等級」，平板編號這種短內容都是最小的 21×21 格。
- 尺寸選擇：
  - **迷你 15×15 mm（只印 QR）**／**迷你 QR 15 mm＋編號（30×15 mm）**：每格 0.6 mm，掃描時平板要拿到借還 iPad 鏡頭前約 **15 公分以內**。
  - **小 30×30 mm**：QR 約 21 mm，距離比較寬鬆，小朋友比較好掃。
  - 產生器下方會顯示 QR 實際大小與每格寬度，太小會出現提醒。
  - 建議兩種尺寸各印一張，先在借還 iPad 上實際試掃再大量列印。
- 可選一般 A4 自己剪，或 A4 標籤貼紙（65／24／21 格），也能自訂尺寸、跳過用過的格子。
- 列印時選「實際大小／100%」、邊界「無」；貼好後覆一層霧面透明膠帶。
- 「借用證」分頁可做老師的 QR 借用證（掃了就帶入姓名，不用登入）。

## 感應卡（選用）

iPad 本身不能讀卡。要買 **13.56MHz、USB（或藍牙）、模擬鍵盤輸出／免驅動** 的感應讀卡機，新款 iPad 用 USB-C 直接接，Lightning 的 iPad 要「Lightning 對 USB 相機轉接器」。

- 登錄：管理 → 感應卡 → 「登錄一張卡」→ 刷卡 → 填姓名（或選「這是平板的貼紙」綁定到某台平板）。也可以把「卡號,姓名,身分,班級座號」名單直接貼進去。
- 平板貼的 NFC 貼紙要買「**抗金屬**」款（iPad 背面是鋁殼）。
- 接上讀卡機後 iPad 會當成接了實體鍵盤，螢幕鍵盤不會自動跳出，所以座號是畫面上的數字鍵。

## 開發測試

```bash
python -m http.server 8766 --directory C:/Users/User/tablet-loan
```

- 瀏覽器主控台：`TLdebug.scan('iPad-01')` 模擬掃描、`TLdebug.fakeCamera(canvas.captureStream())` 用畫布代替鏡頭、`TLdebug.sync()` 立刻和雲端同步。
- 測試時不要碰正式資料：在「管理 → 雲端 → 進階」填本機模擬後端的網址（它會用 `gas/Code.gs` 跑在模擬試算表上）。
- 相機需要 https 或 localhost。
- 改了 `common.js` 或 `app.js` 之後，記得把 `index.html`、`labels.html` 裡的 `?v=` 版本號加一，並把 `sw.js` 的 `CACHE` 版本加一；不然 GitHub Pages 的 10 分鐘快取會讓新舊檔案混在一起。
