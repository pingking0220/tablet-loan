# 平板借還站

取代平板車上的紙本借用簿：在車上放一台「借還平板」，借用人掃描（或點選）平板編號、登入學校 Google 帳號就完成借出；歸還時掃一下就好。紀錄自動寫進 it@lsps.tp.edu.tw 的 Google 試算表。

| 檔案 | 用途 |
|---|---|
| `index.html` + `app.js` | 借還站（放在平板車上的 iPad 開這頁） |
| `labels.html` | 條碼標籤／借用證產生器（在辦公室電腦開來列印） |
| `common.js` | 兩頁共用的設定、平板清單、QR 產生 |
| `gas/Code.gs` | Google 試算表同步後端（已部署在 it@ 帳號） |
| `vendor/` | 掃描（zxing-wasm 3.1.4，C++ ZXing 的 WebAssembly 版）、QR（qrcode-generator 1.4.4）、一維條碼（JsBarcode 3.11.6） |
| `sw.js` / `manifest.webmanifest` | 離線快取（學校網路斷了借還站照樣能開、紀錄先存著） |

## 借還方式（四種可以混用）

1. **鏡頭掃條碼**：平板背面貼 QR Code，對著借還平板的鏡頭（預設前鏡頭）掃。
2. **直接點選**：不想貼標籤就按「👆 不用掃描，直接點選平板編號」，綠色＝在車上可借、橘色＝借出中可還，可以一次選很多台。
3. **感應卡**：外接讀卡機後，刷登錄過的學生證／教職員證／悠遊卡＝帶入借用人；平板背面貼 NFC 貼紙也能刷平板。
4. **條碼槍／手動輸入**：USB／藍牙條碼槍直接掃；或在輸入框打編號（只打數字 7 會自動補成 iPad-07）。

借出時要選身分並**登入學校 Google 帳號**：學生 `@stu.lsps.tp.edu.tw`、老師／職員 `@lsps.tp.edu.tw`。網域不符會被擋下。借完會自動開一個登出分頁、2.5 秒後關掉，避免下一個人選到上一個人的帳號。

歸還不用登入：掃一下（或點選）就好，8 秒內可以按「復原」。前一天以前借出還沒還的會標成「逾期」。

掃到「不在平板清單」的條碼時，右側會留著提示：掃到的內容是什麼、目前清單是哪些編號；管理者可以直接按「把它加入平板清單」（要管理密碼），加完會接著借出／歸還。**借還站和印標籤的電腦是各自存設定的**，兩邊的前綴、範圍要一致。

掃描用 zxing-wasm：每秒約 10 次，輪流解「瞄準框內（保留原解析度）」和「整個畫面」，小標籤對準框比較快掃到，沒對準也掃得到。

## 借還平板（iPad）設定

1. 用 **Safari** 開借還站網址（不要「加入主畫面」：主畫面模式的 Google 登入彈窗在 iOS 上不穩定）。
2. 「設定 → Safari → 相機」改「允許」，不然每次重開都要按允許。
3. 「設定 → Safari → 阻擋彈出式視窗」如果 Google 登入視窗打不開就關掉。
4. 「設定 → 螢幕顯示與亮度 → 自動鎖定」改「永不」，接著充電線。
5. 開「引導使用模式」（設定 → 輔助使用 → 引導使用模式，三下側邊按鈕啟動），學生就跳不出 Safari。用 Jamf 管理的話也可以用單一 App 模式鎖 Safari。
6. 第一次開會進「管理 → 基本設定」：填平板車名稱、平板編號範圍、**改掉預設管理密碼 1234**。
7. 「管理 → 雲端同步」貼上 Apps Script 網址，按「儲存並測試」。

平板若是立在車上面向使用者，用前鏡頭（預設）；平放就到「管理 → 基本設定」換後鏡頭，或按鏡頭畫面右下角 🔄。

## 列印條碼標籤

管理 → 列印條碼 → 開啟標籤產生器（或直接開 `labels.html`）。

- 建議用 **QR Code**：任何角度都掃得到。系統會自動挑「不讓 QR 變大的最高容錯等級」，平板編號這種短內容都是最小的 21×21 格。
- 尺寸選擇：
  - **迷你 15×15 mm（只印 QR）**／**迷你 QR 15 mm＋編號（30×15 mm）**：每格 0.6 mm，掃描時平板要拿到借還 iPad 鏡頭前約 **15 公分以內**。只印 QR 的版本沒有編號文字，適合平板本身已經寫了號碼的情況。
  - **小 30×30 mm**：QR 約 21 mm，距離比較寬鬆，小朋友比較好掃。
  - 產生器下方會顯示 QR 實際大小與每格寬度，太小會出現提醒。模擬測試：掃描引擎需要每格至少 2～3 個像素。
  - 建議兩種尺寸各印一張，先在借還 iPad 上實際試掃再大量列印（iPad 前鏡頭是廣角定焦，離太近會糊）。
- 可選一般 A4 自己剪，或 A4 標籤貼紙（65／24／21 格），也能自訂尺寸、跳過用過的格子。
- 列印時選「實際大小／100%」、邊界「無」；貼好後覆一層透明膠帶。
- 「借用證」分頁可做老師的 QR 借用證（掃了就帶入姓名，不用登入）。

## 感應卡（選用）

iPad 本身不能讀卡。要買 **13.56MHz、USB（或藍牙）、模擬鍵盤輸出／免驅動** 的感應讀卡機，新款 iPad 用 USB-C 直接接，Lightning 的 iPad 要「Lightning 對 USB 相機轉接器」。實體悠遊卡、學生證大多讀得到卡號，建議先買一台試讀幾張再大量登錄。

- 登錄：管理 → 感應卡 → 「登錄一張卡」→ 刷卡 → 填姓名（或選「這是平板的貼紙」綁定到某台平板）。
- 也可以把學務處的「卡號,姓名,身分,班級座號」名單直接貼進去。
- 平板貼的 NFC 貼紙要買「**抗金屬**」款（iPad 背面是鋁殼）。
- 接上讀卡機後 iPad 會當成接了實體鍵盤，螢幕鍵盤不會自動跳出，所以座號已改成畫面上的數字鍵。

## Google 試算表（it@lsps.tp.edu.tw）

- 試算表「平板借還紀錄」：https://docs.google.com/spreadsheets/d/1W1hqv43ThTMO2Cenz8wL2QDTtbvKEN_hbKC5Clj3SlI/edit

  - 「借用紀錄」：一台平板借一次一列（借用人、帳號、身分、借出／歸還時間、狀態）
  - 「感應卡」「設定備份」：借還站的平板清單與感應卡名單備份；換新借還平板時按「管理 → 雲端同步 → 從雲端還原紀錄」就能整套拿回來
- Apps Script 專案「平板借還站後端」：https://script.google.com/d/1BfcficiE6Bj9R_nOCPE4G-fpB6n7DOFjscfjsjAoG50m9h6f6fcmSVId/edit
- 網頁應用程式（同步網址）：執行身分 it@、存取「所有人」。網址記在本機的 `DEPLOY.local.md`（不上傳 GitHub），也可以在 Apps Script「部署 → 管理部署作業」查到。
- **設定連結**：在借還 iPad 上開「借還站網址 + `#gas=` + 同步網址」就會自動填好雲端同步，不用手打。同步網址可以寫入試算表，請不要公開貼出。

紀錄先存在借還平板裡，再自動上傳（斷線時右上角會顯示待上傳筆數，恢復連線自動補傳）。管理頁也能匯出 Excel 可開的 CSV。

## 開發測試

```bash
python -m http.server 8766 --directory C:/Users/User/tablet-loan
```

瀏覽器主控台可用 `TLdebug.scan('iPad-01')` 模擬掃描。相機需要 https 或 localhost。

改了 `common.js` 或 `app.js` 之後，記得把 `index.html`、`labels.html` 裡的 `?v=` 版本號加一，並把 `sw.js` 的 `CACHE` 版本加一；不然 GitHub Pages 的 10 分鐘快取會讓新舊檔案混在一起。
